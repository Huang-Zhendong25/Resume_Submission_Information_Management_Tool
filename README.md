# 投递管理（Delivery Tracker）

一个轻量级、本地运行的投递记录管理工具。启动后在浏览器中打开界面，可方便地新增、修改、删除企业投递记录，并把修改实时同步到 Excel 文件（可自选文件，未指定时自动创建默认文件）。

## ✨ 功能特性

- **三栏分类**：进行中 / 长期无状态更新 / 已淘汰，三个栏目可分别**收起和展开**。
- **企业信息**：企业名称、投递时间（仅月/日，无需年份）、投递岗位、网址、备注。
- **投递状态链**：按顺序添加多个状态（线下投递 / 申请 / 已投递 / 待处理 / 初筛 / 评估中 / 部门筛选 / 测评/笔试 / 面试 / 等待offer / 意向），可单独删除、前后调序，并以彩色标签区分。
- **网址可点击**：在浏览器中直接打开投递记录网址。
- **重点关注**：为笔试、面试等重要节点加星标 + 手动填写标签（如截止日期），卡片高亮并闪烁提醒。
- **淘汰原因**：简历筛选不通过 / 测评未通过 / 笔试未通过 / 一轮面试未通过 / 二轮面试未通过 / HR面试未通过 / 长时间无状态更新 / 投递方式错误。
- **搜索与排序**：按岗位或企业名称搜索；按投递时间早→晚 / 晚→早排序。
- **个性化设置**：整体字号、背景颜色（纯色 / 渐变）、备注背景色、排序方式，均可保存并在重启后保留。

## 📦 环境要求

- Python 3.8 及以上
- [openpyxl](https://openpyxl.readthedocs.io/)（见 `requirements.txt`）

## 🚀 安装与运行

### Windows

1. 双击 `安装依赖.bat` 安装依赖（或执行 `python -m pip install -r requirements.txt`）。
2. 双击 `启动投递管理.bat`，浏览器会自动打开管理界面。
3. 若启动异常，可双击 `启动投递管理_调试.bat` 查看错误信息。

### macOS / Linux

```bash
pip install -r requirements.txt
python app.py
```

浏览器会自动打开 `http://127.0.0.1:<端口>/`；若未自动打开，请手动访问终端中打印的地址。

## 📁 数据文件说明

- **选择已有文件**：在「设置 → 数据文件」点击「浏览选择文件…」（仅 Windows）从文件选择框挑选 `.xlsx` 文件；选定后软件会一直使用该文件进行导入和保存。
- **不指定文件**：留空即可，软件会**自动创建**并使用默认文件 `data/投递.xlsx`，所有修改都会保存到该文件，关闭后不会丢失。
- 首次把旧格式表格转换为新格式前，会自动备份为 `xxx_备份_原始.xlsx`。

## 📊 Excel 表格格式说明

软件会读写工作簿中名为「投递」的工作表，数据按三个分区从上到下排列，每个分区顶部是一行表头：

1. `未淘汰（进行中）`
2. `长期无状态更新`
3. `已淘汰`

表头共 9 列，软件**按表头文字识别列**（列顺序可调整，但表头名称需一致）：

| 表头 | 含义 | 示例 / 取值 |
| --- | --- | --- |
| 企业名称 | 企业 / 单位名称 | 示例企业 |
| 投递时间 | 仅月份与日期，无年份 | `9月13日`（也支持 `9-13`、`9.13`） |
| 投递状态 | 多个状态用 `→` 连接 | `已投递 → 测评/笔试 → 面试` |
| 投递岗位 | 应聘岗位 | 示例岗位 |
| 网址 | 投递记录网址 | `https://...` |
| 备注 | 其他注意事项 | 截止 10月5日 |
| 重点关注 | 是否为重点关注 | `★` 或留空 |
| 重点标签 | 重点关注的手动标签 | 笔试截止 10月5日 10:00 |
| 淘汰原因 | 仅「已淘汰」分区填写 | 简历筛选不通过 |

几点说明：

- **新建或使用默认文件**时，软件会自动生成以上结构，无需手动准备。
- **导入已有文件**时，软件按表头名称识别；若识别不到（例如原来手写的旧表），会尽量自动解析并转换，转换前自动备份为 `xxx_备份_原始.xlsx`。
- 投递状态可选项：`线下投递 / 申请 / 已投递 / 待处理 / 初筛 / 评估中 / 部门筛选 / 测评/笔试 / 面试 / 等待offer / 意向`。
- 淘汰原因可选项：`简历筛选不通过 / 测评未通过 / 笔试未通过 / 一轮面试未通过 / 二轮面试未通过 / HR面试未通过 / 长时间无状态更新 / 投递方式错误`。

## 🛠 技术说明

- 后端使用 Python 标准库 `http.server` 提供本地服务，`openpyxl` 负责 Excel 读写。
- 前端为纯 HTML/CSS/JavaScript，无需任何前端构建工具。
- 数据与界面设置均保存在本机，不依赖任何第三方网络服务。
